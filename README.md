# Notch
Silly app that prevents acne and breakouts by alarming and notifying others if you touch your face.

After cloning the repo. Please download a older version of [python](https://www.python.org/downloads/release/python-3119/), the specific version of media pipe used is only on 3.11 and below.

After that, run the following 3 commands:
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

And lastly:
python notch.py

Press ESC to exit!
